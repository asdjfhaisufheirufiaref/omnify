# Omnify

**Omnify** — локальний настільний набір інструментів для Linux, який об'єднує
календар, таймери, нотатки, калькулятор, менеджер задач і приватний браузер
в одному GTK 4-застосунку.

Проєкт створено як навчальний програмний продукт: він працює локально, не
потребує облікового запису або хмарного сервера, а всі важливі дані
зберігаються у звичайних файлах на диску користувача.

![Логотип Omnify](omnify_logo.png)

## Основні можливості

| Модуль | Що робить |
| --- | --- |
| **Dashboard** | Головний екран із привітанням, годинником, швидкими діями (нова нотатка, щоденник), оглядом нотаток, останніми нотатками з переходом у редактор, станом бекапів і плитками всіх модулів. |
| **Notes** | Markdown-нотатки з папками, тегами (зокрема масовим перейменуванням), пошуком, чеклістами, таблицями, картинками, LaTeX-формулами, preview, експортом, бекапами та синхронізацією. |
| **Calendar** | Тижневий, денний і місячний перегляд, події, нагадування, повторення, пошук, статистика, звички, швидке додавання фразою та нотатки зустрічей. |
| **Timer / Stopwatch** | Кілька таймерів, пресети, робота у фоні, звуки, нагадування, laps. |
| **Alarm** | Постійні будильники, повторення за днями тижня, snooze і власний звук. |
| **Calculator** | Науковий калькулятор, точна арифметика, матриці, похідні, інтеграли, графіки та історія. |
| **Task Manager** | Процеси, продуктивність, сервіси, автозапуск, користувачі та безпечне завершення процесів. |
| **Browser** | Окремий LibreWolf/Firefox із керованим профілем, захистом приватності, блокуванням трекерів, пошуковими скороченнями, локальним списком для читання і режимом Tor Browser. |
| **Command center** | Палітра команд, швидкий перехід до нотаток, редаговані клавіатурні скорочення (зокрема глобальні) та швидке захоплення тексту. |
| **Module windows** | Будь-який модуль можна відкрити в окремому вікні; воно використовує той самий живий екземпляр, а закриття повертає модуль у головне вікно. |
| **Plugins / AI** | Вбудовані й зовнішні плагіни з явним підтвердженням довіри; AI-помічник для локальних моделей і хмарних OpenAI-сумісних сервісів. |
| **Settings** | Англійська/українська мова, теми, акценти, шрифти, радіус, фон, імпорт/експорт теми, керування бекапами, плагіни, AI та скидання даних. |

## Технології

- **Python 3.10+** (перевірено на Python 3.14);
- **GTK 4** через `PyGObject` (`gi`);
- **стандартна бібліотека Python** — без обов'язкових pip-пакетів;
- **cairo/Pango** — для PDF-експорту нотаток;
- **Markdown** — основний формат зберігання нотаток;
- **unittest** — автоматизовані тести.

GTK імпортується ліниво в модулях, тому більшість логіки можна тестувати
без запущеного графічного сесії.

## Встановлення

### 1. Системні залежності

Для Arch/CachyOS:

```bash
sudo pacman -S python-gobject gtk4
```

Для Debian/Ubuntu:

```bash
sudo apt install python3-gi gir1.2-gtk-4.0
```

Для Fedora:

```bash
sudo dnf install python3-gobject gtk4
```

`LibreWolf` або `Firefox` потрібні лише для модуля Browser. Вони не є
обов'язковими для Notes, Calendar, Timer та інших інструментів.

### 2. Запуск із папки проєкту

```bash
cd /home/sillycat/projects/omnify
python3 -m omnify
```

### 3. Встановлення ярликів

```bash
./install.sh
omnify
```

`install.sh` створює символічне посилання на пакет, командний запуск
`omnify`, іконку, desktop-записи та autostart для відновлення таймерів після
входу в систему. Скрипт можна запускати повторно після оновлення коду.

Корисні команди:

```bash
omnify                        # запустити або активувати єдиний процес
omnify --module notes         # відкрити конкретний модуль
omnify --module notes --window # відкрити модуль в окремому вікні
omnify --command timer.start  # виконати команду в запущеному процесі
omnify-browser                # відкрити керований LibreWolf/Firefox
omnify-browser --tor          # відкрити Tor Browser
```

## Видалення

```bash
./uninstall.sh            # інтерактивно
./uninstall.sh --yes      # без підтвердження
./uninstall.sh --dry-run  # лише показати план
```

За замовчуванням скрипт прибирає ярлики, desktop-записи, autostart, іконку,
символічне посилання на пакет, дані застосунку, профіль браузера та нотатки.
Вихідний код проєкту залишається; для його видалення є `--remove-project`.
Опція `--keep-data` зберігає нотатки й налаштування.

**Бекапи не видаляються ніколи** — ні за замовчуванням, ні з
`--remove-project`. Скрипт захищає типову папку `backups`, шлях із
`OMNIFY_BACKUP_DIR` і власну папку, збережену в `backup.json`. Щоб видалити
бекапи, це потрібно зробити вручну у файловому менеджері.

## Палітра команд і скорочення

- `Ctrl+Shift+P` — палітра всіх команд і дій;
- `Ctrl+P` — швидкий перехід до нотатки, модуля або команди;
- `Ctrl+,` — налаштування;
- `Ctrl+Alt+N` — швидке захоплення тексту в нову нотатку або щоденник.

Кожне скорочення змінюється в **Settings → Keyboard shortcuts** — не лише
глобальні, а й дії окремих модулів. Для команди можна увімкнути режим
«Глобальне»: тоді вона спрацьовує навіть коли вікно Omnify сховано в лоток.
Наприклад, можна призначити `Alt+F4` на `timer.start`: вікно закриється, а
таймер запуститься, бо процес із лотком продовжує працювати.

Будь-який модуль можна відокремити в окреме вікно: кнопкою біля заголовка
sidebar, командою палітри **Open … in a separate window** або запуском
`omnify --module notes --window`. Окреме вікно використовує той самий живий
екземпляр модуля, тому таймери й будильники не дублюються, а зміни видно
обом вікнам. У головному вікні лишається заглушка з кнопками **Focus window**
і **Return to main window**; закриття окремого вікна повертає модуль на його
місце. Desktop-записи окремих модулів використовують саме `--window`.

## Шаблони та швидке захоплення

Notes підтримує вбудовані й користувацькі шаблони. У шаблонах працюють
змінні `{{date}}`, `{{time}}`, `{{datetime}}`, `{{date:YYYY-MM-DD}}`,
`{{yesterday}}`, `{{tomorrow}}`, `{{weekday}}`, `{{title}}`, `{{folder}}`,
`{{uuid}}`, `{{random}}`, `{{clipboard}}`, `{{prompt:Питання}}` і
`{{cursor}}`. Користувацькі шаблони створюються в **Notes → New from
template… → Manage templates…**.

Швидке захоплення відкриває окреме вікно, підставляє буфер обміну та зберігає
текст у нову нотатку або сьогоднішній щоденник.

## Плагіни

Плагіни працюють за принципом «поклади теку й увімкни»:

1. Відкрийте **Settings → Plugins → Open plugins folder**.
2. Додайте теку з `plugin.json` і точкою входу (наприклад, `plugin.py`).
3. Натисніть **Rescan**, потім **Enable**.

Вбудовані плагіни постачаються разом з Omnify. Зовнішні плагіни виконують
Python-код із правами користувача, тому до першого запуску показується
діалог довіри. Мережевого магазину плагінів немає: ви самі вирішуєте, що
встановлювати.

## AI-помічник

**AI Assistant** — перший вбудований плагін. Він вимкнений за замовчуванням;
увімкніть його в **Settings → Plugins**. Підтримуються:

- локальні OpenAI-сумісні сервери (Ollama, LM Studio, llama.cpp, LocalAI,
  vLLM) — типово `http://localhost:11434/v1`;
- OpenAI, OpenRouter і будь-який власний OpenAI-сумісний шлюз;
- власний API-ключ у налаштуваннях або через `OMNIFY_AI_API_KEY`.

Хмарні провайдери один раз показують попередження про конфіденційність:
надісланий текст залишає комп'ютер. Для приватних нотаток краще локальна
модель. Команди AI: звичайне запитання, запитання про поточну нотатку,
підсумок нотатки, створення події календаря з природної мови та дослідницька
нотатка з відкриттям пошуку в браузері.

## Календар і браузер

Календар має рядок **Quick add** (або `Ctrl+Shift+A` у модулі Calendar).
Він розуміє детерміновані фрази без ШІ та без мережі:

- `Lunch with Ann tomorrow at 13:00`;
- `Dentist on Friday 10:00-11:30`;
- `Standup next monday 9am for 15 minutes`;
- `Іспит 20.11.2026 14:00`;
- `Планування на 20 листопада о 10:00`;
- `Deep work tomorrow` — подія на весь день.

Якщо в події заповнені місце, учасники або нотатки, кнопка **Meeting note**
в діалозі редагування створює Markdown-нотатку з порядком денним, учасниками
та чеклістом завдань.

У браузері пошуковий рядок підтримує скорочення: `!w Python`, `!yt lofi`,
`!gh omnify`, `!so traceback`, `!aur librewolf`, `!maps Kyiv` тощо. Повний
список доступний у підказці поля. **Reading list** зберігає сторінки локально
в Omnify (без акаунта й синхронізації), дозволяє відкривати їх по одній або
всі разом і видаляти записи. Остання відкрита сторінка підставляється в поле
автоматично, а команда `browser.save_page` зберігає її одним рухом.

Виділений на сторінці текст можна одразу відправити в Omnify через
контекстне меню: **Move selection to a new note** створює нотатку з
посиланням на джерело, а **Solve in Calculator** відкриває Калькулятор із
нормалізованим виразом. Для цього використовується локальне розширення та
loopback-місток на `127.0.0.1` із випадковим токеном; виділений текст не
залишає комп'ютер.

## Нотатки

Нотатки — локальні Markdown-файли, а не записи у закритій базі даних.

```
notes/
├── План.md
├── Робота/
│   └── Звіт.md
├── assets/
│   └── <id-нотатки>/
│       └── photo.png
├── .trash/                 # нотатки, переміщені в кошик
└── .history/               # автоматичні та ручні версії нотаток
```

Кожен файл має front matter:

```markdown
---
id: 4f3c2a1b...
title: "План на тиждень"
tags: ["навчання", "плани"]
pinned: true
updated_at: 2026-11-11T12:00:00+00:00
---

# План

- [ ] підготувати практичні
- [x] зробити commit
```

Можливості Notes:

- створення, редагування та переміщення нотаток у кошик;
- відновлення нотаток із кошика та остаточне очищення;
- створення незалежної копії нотатки разом із картинками;
- вбудовані шаблони для плану дня, зустрічі, навчання та тижневого огляду;
- щоденна нотатка в папці `Journal`, яка відкривається однією кнопкою;
- автоматична історія версій (до 20 знімків на нотатку), ручне збереження
  версії, перегляд і відкат до попереднього стану;
- пошук і заміна в тексті нотатки з урахуванням регістру (`Ctrl+H`);
- папки, перейменування папок, переміщення нотаток і фільтр за папкою;
- теги через кому, підказки тегів, фільтр за тегом і пошук `#тег`;
- закріплення нотаток;
- Markdown-preview без WebKit;
- LaTeX-формули у preview, HTML і PDF без KaTeX, Node чи WebKit;
- чеклісти, які можна перемикати прямо у preview;
- таблиці, списки, цитати, код, посилання та зображення;
- вставка картинки з файлу або з буфера обміну через `Ctrl+V`;
- збереження зображень у `notes/assets/<id>/`;
- експорт однієї нотатки в HTML, PDF або портативну Markdown-теку з картинками;
- експорт усіх нотаток у теку з `index.html` або портативний Markdown-набір з `index.md`;
- імпорт зовнішніх Markdown-файлів;
- ZIP-бекапи вручну й автоматично з налаштовуваним інтервалом
  (хвилини, години, дні або тижні);
- власна папка бекапів, менеджер архівів із зіроньками, відновленням,
  перевіркою цілісності та ручним видаленням; попередження про ліміт є
  опційним, а типово ліміту немає (0);
- зірка `_STAR.backup` захищає окремий архів від автоматичного очищення;
- автоматичне видалення старих архівів є **опційним** і ніколи не чіпає
  архіви із зіркою, старі legacy-архіви або файли інших програм.

### LaTeX у нотатках

Формули працюють офлайн: Omnify перетворює практичне підмножину TeX у
Unicode та Pango/HTML-розмітку, тому не потрібні KaTeX, Node, WebKit або
зовнішній компілятор. Inline-формула пишеться як `$x^2 + y_1$` або
`\(x^2 + y_1\)`, display-формула — як блок:

```markdown
$$
\frac{a+b}{c} = \sqrt[3]{x}
$$
```

Підтримуються грецькі літери, стрілки, множини, дроби, корені, верхні та
нижні індекси, акценти, `\text{...}`, `\mathbf{...}`, `\mathbb{...}`,
прості матриці (`matrix`, `pmatrix`, `bmatrix`, `vmatrix`, `cases`) і
типові функції (`\sin`, `\log`, `\lim`). Невідома команда не зникає —
вона показується буквально. Команди палітри **Insert inline LaTeX math**
і **Insert display LaTeX math** вставляють заготовку у вибране місце.
- відновлення з бекапу зі страхувальною копією;
- одностороння синхронізація з папкою;
- двостороння синхронізація за стабільним `id` з вибором новішої версії;
- гарячі клавіші `Ctrl+S`, `Ctrl+F`, `Ctrl+H`, `Ctrl+B`, `Ctrl+I`, `Ctrl+K`.

Дані застосунку за замовчуванням лежать у:

- `notes/` — Markdown-нотатки та зображення;
- `~/.local/share/omnify/` — налаштування, стан і бекапи;
- `~/.local/share/omnify/backups/` — ZIP-архіви (типово; папку можна
  змінити в **Settings → Backups**);
- `notes/` і локальні дані браузера додані до `.gitignore` і не повинні
  потрапляти в Git.

## Перевірка

```bash
python3 -m py_compile $(find omnify tests -name '*.py')
python3 -m unittest discover -s tests
```

Стан перевірки на момент останнього оновлення:

```text
Ran 652 tests in ...
OK
```

Окремі приклади запуску тестів:

```bash
python3 -m unittest tests.test_notes_store -v
python3 -m unittest tests.test_notes_render -v
python3 -m unittest tests.test_notes_engine -v
```

## Приклади використання

Створити нотатку з чеклістом:

1. Відкрити **Notes**.
2. Натиснути `+`.
3. Ввести назву.
4. Натиснути `☑` або набрати `- [ ] завдання`.
5. Перемкнути **Preview** і натиснути чекбокс.

Додати картинку:

1. Поставити курсор у нотатці.
2. Вставити зображення з буфера через `Ctrl+V` або натиснути `🖼`.
3. Файл з'явиться в `notes/assets/<id>/`.

Зробити резервну копію:

1. Відкрити меню `⋮` біля нотатки або **Settings → Backups**.
2. Вибрати **Backup now**.
3. Архів з'явиться в налаштованій папці (типово
   `~/.local/share/omnify/backups/`).
4. У **Settings → Backups** можна змінити інтервал, папку, ліміт
   (0 = без обмежень, типово), увімкнути безпечне очищення старих архівів
   або позначити архів зіркою.

Відкрити модуль в окремому вікні:

1. Відкрити потрібний модуль у головному вікні.
2. Натиснути кнопку вікна біля заголовка **Omnify** у sidebar або виконати
   команду палітри **Open current module in a separate window**.
3. Закрити окреме вікно, щоб повернути модуль у головне вікно; таймери
   продовжують працювати весь час.

## Обмеження

- Синхронізація з хмарою не є вбудованим акаунтом: Omnify працює з
  локальною або користувацькою текою (наприклад, Syncthing/Dropbox).
- Двостороння синхронізація не поширює видалення нотаток; вона об'єднує
  файли за `id`, щоб випадково не втратити дані.
- PDF-експорт навмисно простий: підтримуються основні Markdown-блоки,
  таблиці та зображення, але це не повноцінний друкарський рушій.
- Browser потребує встановленого LibreWolf або Firefox; Tor Browser
  встановлюється окремо.
- Figma-прототип у цьому репозиторії замінений робочим GTK-прототипом і
  редагованими SVG-wireframes у `docs/wireframes/` (їх можна імпортувати у
  Figma); для оцінювання практичної №8 див. відповідний розділ у
  `ПРАКТИЧНІ_РОБОТИ.md`.
