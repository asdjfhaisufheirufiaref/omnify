# Omnify

**Omnify** — локальний настільний набір інструментів для Linux, який об'єднує
календар, таймери, нотатки, калькулятор, менеджер задач і приватний браузер
в одному GTK 4-застосунку.

Проєкт створено як навчальний програмний продукт: він працює локально, не
потребує облікового запису або хмарного сервера, а всі важливі дані
зберігаються у звичайних файлах на диску користувача.

![Логотип Omnify](omnify_logo.png)

## Основні можливості

| Модуль | Що робить |
| --- | --- |
| **Dashboard** | Головний екран із привітанням, годинником, швидкими діями (нова нотатка, щоденник), оглядом нотаток, станом бекапів і плитками всіх модулів. |
| **Notes** | Markdown-нотатки з папками, тегами (зокрема масовим перейменуванням), пошуком, чеклістами, таблицями, картинками, preview, експортом, бекапами та синхронізацією. |
| **Calendar** | Тижневий, денний і місячний перегляд, події, нагадування, повторення, пошук, статистика та звички. |
| **Timer / Stopwatch** | Кілька таймерів, пресети, робота у фоні, звуки, нагадування, laps. |
| **Alarm** | Постійні будильники, повторення за днями тижня, snooze і власний звук. |
| **Calculator** | Науковий калькулятор, точна арифметика, матриці, похідні, інтеграли, графіки та історія. |
| **Task Manager** | Процеси, продуктивність, сервіси, автозапуск, користувачі та безпечне завершення процесів. |
| **Browser** | Окремий LibreWolf/Firefox із керованим профілем, захистом приватності, блокуванням трекерів і режимом Tor Browser. |
| **Settings** | Англійська/українська мова, теми, акценти, шрифти, радіус, фон, імпорт/експорт теми, керування бекапами та скидання даних. |

## Технології

- **Python 3.10+** (перевірено на Python 3.14);
- **GTK 4** через `PyGObject` (`gi`);
- **стандартна бібліотека Python** — без обов'язкових pip-пакетів;
- **cairo/Pango** — для PDF-експорту нотаток;
- **Markdown** — основний формат зберігання нотаток;
- **unittest** — автоматизовані тести.

GTK імпортується ліниво в модулях, тому більшість логіки можна тестувати
без запущеного графічного сесії.

## Встановлення

### 1. Системні залежності

Для Arch/CachyOS:

```bash
sudo pacman -S python-gobject gtk4
```

Для Debian/Ubuntu:

```bash
sudo apt install python3-gi gir1.2-gtk-4.0
```

Для Fedora:

```bash
sudo dnf install python3-gobject gtk4
```

`LibreWolf` або `Firefox` потрібні лише для модуля Browser. Вони не є
обов'язковими для Notes, Calendar, Timer та інших інструментів.

### 2. Запуск із папки проєкту

```bash
cd /home/sillycat/projects/omnify
python3 -m omnify
```

### 3. Встановлення ярликів

```bash
./install.sh
omnify
```

`install.sh` створює символічне посилання на пакет, командний запуск
`omnify`, іконку, desktop-записи та autostart для відновлення таймерів після
входу в систему. Скрипт можна запускати повторно після оновлення коду.

Корисні команди:

```bash
omnify                 # запустити або активувати єдиний процес
omnify --module notes  # відкрити конкретний модуль
omnify-browser         # відкрити керований LibreWolf/Firefox
omnify-browser --tor   # відкрити Tor Browser
```

## Видалення

```bash
./uninstall.sh            # інтерактивно
./uninstall.sh --yes      # без підтвердження
./uninstall.sh --dry-run  # лише показати план
```

За замовчуванням скрипт прибирає ярлики, desktop-записи, autostart, іконку,
символічне посилання на пакет, дані застосунку, профіль браузера та нотатки.
Вихідний код проєкту залишається; для його видалення є `--remove-project`.
Опція `--keep-data` зберігає нотатки й налаштування.

**Бекапи не видаляються ніколи** — ні за замовчуванням, ні з
`--remove-project`. Скрипт захищає типову папку `backups`, шлях із
`OMNIFY_BACKUP_DIR` і власну папку, збережену в `backup.json`. Щоб видалити
бекапи, це потрібно зробити вручну у файловому менеджері.

## Нотатки

Нотатки — локальні Markdown-файли, а не записи у закритій базі даних.

```
notes/
├── План.md
├── Робота/
│   └── Звіт.md
├── assets/
│   └── <id-нотатки>/
│       └── photo.png
├── .trash/                 # нотатки, переміщені в кошик
└── .history/               # автоматичні та ручні версії нотаток
```

Кожен файл має front matter:

```markdown
---
id: 4f3c2a1b...
title: "План на тиждень"
tags: ["навчання", "плани"]
pinned: true
updated_at: 2026-11-11T12:00:00+00:00
---

# План

- [ ] підготувати практичні
- [x] зробити commit
```

Можливості Notes:

- створення, редагування та переміщення нотаток у кошик;
- відновлення нотаток із кошика та остаточне очищення;
- створення незалежної копії нотатки разом із картинками;
- вбудовані шаблони для плану дня, зустрічі, навчання та тижневого огляду;
- щоденна нотатка в папці `Journal`, яка відкривається однією кнопкою;
- автоматична історія версій (до 20 знімків на нотатку), ручне збереження
  версії, перегляд і відкат до попереднього стану;
- пошук і заміна в тексті нотатки з урахуванням регістру (`Ctrl+H`);
- папки, перейменування папок, переміщення нотаток і фільтр за папкою;
- теги через кому, підказки тегів, фільтр за тегом і пошук `#тег`;
- закріплення нотаток;
- Markdown-preview без WebKit;
- чеклісти, які можна перемикати прямо у preview;
- таблиці, списки, цитати, код, посилання та зображення;
- вставка картинки з файлу або з буфера обміну через `Ctrl+V`;
- збереження зображень у `notes/assets/<id>/`;
- експорт однієї нотатки в HTML, PDF або портативну Markdown-теку з картинками;
- експорт усіх нотаток у теку з `index.html` або портативний Markdown-набір з `index.md`;
- імпорт зовнішніх Markdown-файлів;
- ZIP-бекапи вручну й автоматично з налаштовуваним інтервалом
  (хвилини, години, дні або тижні);
- власна папка бекапів, менеджер архівів із зіроньками, відновленням,
  перевіркою цілісності та ручним видаленням; попередження про ліміт є
  опційним, а типово ліміту немає (0);
- зірка `_STAR.backup` захищає окремий архів від автоматичного очищення;
- автоматичне видалення старих архівів є **опційним** і ніколи не чіпає
  архіви із зіркою, старі legacy-архіви або файли інших програм;
- відновлення з бекапу зі страхувальною копією;
- одностороння синхронізація з папкою;
- двостороння синхронізація за стабільним `id` з вибором новішої версії;
- гарячі клавіші `Ctrl+S`, `Ctrl+F`, `Ctrl+H`, `Ctrl+B`, `Ctrl+I`, `Ctrl+K`.

Дані застосунку за замовчуванням лежать у:

- `notes/` — Markdown-нотатки та зображення;
- `~/.local/share/omnify/` — налаштування, стан і бекапи;
- `~/.local/share/omnify/backups/` — ZIP-архіви (типово; папку можна
  змінити в **Settings → Backups**);
- `notes/` і локальні дані браузера додані до `.gitignore` і не повинні
  потрапляти в Git.

## Структура проєкту

```text
omnify/
├── omnify/
│   ├── app/shell.py           # GTK Application, вікно, sidebar, модулі
│   ├── app/backup_ui.py       # Settings → Backups і менеджер архівів
│   ├── core/backup.py         # політика, зірки, безпечне очищення
│   ├── core/                  # storage, i18n, theme, context, tray, alerts
│   ├── modules/
│   │   ├── notes.py           # GTK-інтерфейс Notes
│   │   ├── notes_engine.py    # Note, NoteStore, бекапи, sync
│   │   ├── notes_render.py    # Markdown → HTML/PDF
│   │   ├── notes_preview.py   # Markdown → GTK preview
│   │   ├── calculator.py      # Calculator UI
│   │   ├── calendar.py        # Calendar UI
│   │   ├── timer.py           # Timer UI
│   │   └── ...
│   ├── locales/               # англійська та українська локалізація
│   └── main.py                # точка входу
├── tests/                     # unittest-тести
├── install.sh                 # встановлення ярликів
├── uninstall.sh               # безпечне видалення; бекапи зберігаються
├── pyproject.toml
├── PROJECT_STATUS.md
├── README.md
└── ПРАКТИЧНІ_РОБОТИ.md
```

## Перевірка

```bash
python3 -m py_compile $(find omnify tests -name '*.py')
python3 -m unittest discover -s tests
```

Стан перевірки на момент останнього оновлення:

```text
Ran 473 tests in ...
OK
```

Окремі приклади запуску тестів:

```bash
python3 -m unittest tests.test_notes_store -v
python3 -m unittest tests.test_notes_render -v
python3 -m unittest tests.test_notes_engine -v
```

## Приклади використання

Створити нотатку з чеклістом:

1. Відкрити **Notes**.
2. Натиснути `+`.
3. Ввести назву.
4. Натиснути `☑` або набрати `- [ ] завдання`.
5. Перемкнути **Preview** і натиснути чекбокс.

Додати картинку:

1. Поставити курсор у нотатці.
2. Вставити зображення з буфера через `Ctrl+V` або натиснути `🖼`.
3. Файл з'явиться в `notes/assets/<id>/`.

Зробити резервну копію:

1. Відкрити меню `⋮` біля нотатки або **Settings → Backups**.
2. Вибрати **Backup now**.
3. Архів з'явиться в налаштованій папці (типово
   `~/.local/share/omnify/backups/`).
4. У **Settings → Backups** можна змінити інтервал, папку, ліміт
   (0 = без обмежень, типово), увімкнути безпечне очищення старих архівів
   або позначити архів зіркою.

## Обмеження

- Синхронізація з хмарою не є вбудованим акаунтом: Omnify працює з
  локальною або користувацькою текою (наприклад, Syncthing/Dropbox).
- Двостороння синхронізація не поширює видалення нотаток; вона об'єднує
  файли за `id`, щоб випадково не втратити дані.
- PDF-експорт навмисно простий: підтримуються основні Markdown-блоки,
  таблиці та зображення, але це не повноцінний друкарський рушій.
- Browser потребує встановленого LibreWolf або Firefox; Tor Browser
  встановлюється окремо.
- Figma-прототип у цьому репозиторії замінений робочим GTK-прототипом і
  редагованими SVG-wireframes у `docs/wireframes/` (їх можна імпортувати у
  Figma); для оцінювання практичної №8 див. відповідний розділ у
  `ПРАКТИЧНІ_РОБОТИ.md`.
